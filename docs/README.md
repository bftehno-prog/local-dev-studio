# Local Dev Studio Documentation

Local Dev Studio is a Windows desktop app for managing local development servers for Next.js, Vite, Astro, PHP and static HTML projects.

## Features

- Project launch and stop from a desktop UI.
- Live preview, external browser open and QR network preview.
- Port manager, logs, templates and sandboxes.
- Runtime diagnostics for Node.js, package managers, Git, PHP and Rust tooling.
- Safe command construction from allow-listed project types and package managers.
