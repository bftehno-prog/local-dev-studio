# User Guide

## Add a Project

Open Projects, choose a folder or paste a project path, then click Add.

## Start and Stop

Use project row actions to start, stop or restart. Start All and Stop All are available from the header and tray menu.

## Live Preview

When a server is running, Live Preview shows its local URL. Use refresh, copy URL or open in browser.

## Network Preview

If network preview is enabled, the app shows a LAN URL and QR code. Devices must be on the same network and firewall rules must allow access.

## Logs

Open Logs to filter by level and search messages.

## Templates

Use Templates to create projects from built-in templates or import ZIP templates.

## Diagnostics

Open Settings and use Diagnostics to check runtimes, PATH and app folders.
